# 宝塔部署（IDEA 插件）

在 IDEA 右侧工具栏把打包产物一键发到宝塔服务器：**打包 → 上传 → 解压 → 重启**，全程走宝塔面板 API，不需要在服务器上开 SSH。

作者：MrMao14。桌面版见 [bt-deploy](https://github.com/MrMao14/bt-deploy)。

## 界面

- 顶部选择**面板**，右上角有「刷新」状态按钮和「设置」按钮
- 「设置」里集中管理：新增/编辑/删除面板，新增/编辑/删除部署配置；面板的「测试连接」也在面板设置里
- 「部署配置」页底部支持按历史版本 JSON 格式导入/导出；导出不含 API 密钥，导入时同名配置覆盖、其余追加
- 中间是固定高度的**部署配置卡片**，展示远程目录、本地路径数、重启方式和服务运行状态
- 每个卡片自带操作：勾选「打包」后点 **部署**，以及 **查看日志 / 操作**；查看服务器项目日志并可在弹窗内下载
- 部署配置的编辑和删除统一放在右上角「设置」里
- 底部固定展示当前选中配置的**部署日志**，部署时实时追加并支持清空

「部署」按左侧「打包」勾选状态执行：默认勾选，先执行 IDEA 的 **Build Project**（构建全部模块），构建成功后再上传；取消勾选则直接上传当前已经存在的产物。

## 功能

- 多个面板，面板与部署配置在 IDE 内全局保存，所有项目共享
- 面板地址 / API 密钥配置，面板设置内可「测试连接」
- 一个部署配置可添加多个目录、文件或已有 `.zip`，合并成一个包上传
- 打开部署配置时会从面板读取网站目录和 Java 项目：远程目录可直接选，Java 项目选中后自动带出项目目录，服务名也提供常用下拉项；读取失败仍可手动输入
- 卡片展示服务状态：运行中 / 已停止 / 未安装 / 未知；右上角「刷新」可重新查询
- 「操作」下拉支持启动、停止、重启、还原备份；Java 项目走项目接口，其他配置操作对应系统服务
- 「查看日志」读取服务器上项目远程目录下的 `logs/` 文件，使用 IDEA 日志配色自动高亮级别；支持文件选择、自动刷新、大文件分段查看、搜索、字号调整、全屏和下载
- 上传到远程目录的 `bak/` 下自动保留最近 3 份备份
- 「还原备份」可选择 `bak/` 中的历史部署包重新解压，并按配置执行部署后动作
- 解压后按配置执行：不重启 / 重载 Web 服务器 / 重启系统服务 / 重启 Java 项目
- 底部部署日志随卡片切换，按部署配置区分并可清空
- 部署成功/失败弹出通知

## 前置条件

服务器端需要在宝塔面板 **面板设置 → API 接口** 打开 API、生成密钥，并建议配置 IP 白名单。面板端口要能从本机访问。

## 使用

1. 打开 IDEA 右侧的「宝塔部署」
2. 点右上角「设置」→「面板」→「新增面板」，填写面板地址（如 `https://1.2.3.4:8888`）和 API 密钥，在面板设置里点「测试连接」
3. 同一个设置的「部署配置」页选择面板，点「新增配置」，选择本地路径、远程目录、Java 项目和部署后动作；远程目录旁的「刷新」会重新从面板读取网站/Java 项目列表，也可以使用底部的「导入配置 / 导出配置」
4. 回到主界面，按需勾选卡片上的「打包」，再点「部署」；也可以直接使用「查看日志」或「操作」下拉
5. 底部日志会实时显示本次部署；卡片上的「查看日志」会打开服务器项目日志弹窗，并可在弹窗内下载

本地选择目录时默认保留目录名：选 `.../dist` 部署到 `/www/wwwroot/site`，结果是 `/www/wwwroot/site/dist/…`；取消勾选「保留目录名」则把目录内容直接铺到目标目录。

## 配置与日志

- 面板、部署配置保存在 IDEA 全局配置中，所有项目共享，不再写入项目 `.idea`
- 部署日志固定显示在工具窗口底部，按部署配置区分并保存在 IDE 内存中，重启 IDE 后清空
- 服务状态在打开工具窗口、切换面板、刷新、部署完成后自动查询

## 开发

需要 JDK 25（IDEA 2026.3 自带的 JBR 即可，把 `JAVA_HOME` 指向它）。项目默认从 `local.properties` 读取本机 IDEA 安装目录作为编译平台，避免下载完整 IDEA 分发包：

```properties
platformLocalPath=C:/Users/you/AppData/Local/Programs/IntelliJ IDEA
```

没有 `local.properties` 时会改为下载 IntelliJ IDEA 2026.3。IDEA 里导入 Gradle 工程时，**Gradle JVM** 也选 2026.3 自带的 JBR 25。

```bash
# JAVA_HOME 指向 IDEA 自带的 JBR（Windows 示例）
export JAVA_HOME="$LOCALAPPDATA/Programs/IntelliJ IDEA/jbr"

./gradlew runIde        # 启动带插件的沙箱 IDEA
./gradlew buildPlugin   # 产物在 build/distributions/
```

插件基于 IntelliJ Platform 2026.3（since-build `263`）。
